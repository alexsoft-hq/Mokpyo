# Contributing to Mokpyo

Mokpyo is maintained by [ALEXSOFT](https://alexsoft.co.kr/) as a self-hosted,
MIT-licensed team goals and OKR tool. See [README.md](README.md) for setup.

## Questions, bugs and changes

Use [GitHub Issues](https://github.com/alexsoft-hq/mokpyo-oss/issues) for reproducible
bugs and focused feature proposals. Include the version/commit, deployment method,
steps to reproduce, expected result and relevant **redacted** logs. Remove personal
data, customer names, tokens and internal network details from screenshots and logs.
Report security issues privately using [SECURITY.md](SECURITY.md).

For a substantial change, discuss the scope in an issue before implementing it.
Keep pull requests focused and explain the problem, the change and verification.
Preserve database compatibility or document the migration and recovery procedure.
Run `npm run ci` before submitting a code change. Do not include `.env` files,
database dumps, uploads, dependencies or generated application bundles.

Contributions are provided under the repository's MIT license. Only contribute
material you have the right to license, and preserve third-party license notices.

## Support boundaries

Community maintenance is best effort. Issues do not include a guaranteed response
time, implementation commitment, hosting, backup service or availability SLA.
Operators are responsible for their deployments and their users' data.

Architecture consulting, installation, migration, integration and custom development
are available through separately scoped agreements with ALEXSOFT:
[discuss a project](https://alexsoft.co.kr/diagnosis/#inquiry) or email
[contact@alexsoft.co.kr](mailto:contact@alexsoft.co.kr).
